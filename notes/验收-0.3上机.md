## 烧录

分区表未变（`partitions-moji.csv` 未动），但为了强制从 ota_0 启动并刷新 bootloader，按整片刷（不含 `srmodels.bin`，模型分区 0.2 起未变、仍在 `0x800000`）：

```
0x0      bootloader.bin
0x8000   partition-table.bin
0xf000   ota_data_initial.bin
0x20000  hermes_gadget.bin
```

- 判据：`Hash of data verified.` + `Hard resetting via RTS pin...` → 均出现（`FLASH_OK attempt 1`）
- 坑：COM5 被一个**提权**运行的 `pythonw.exe`（gadget-relay 环境，12:00 起）占着，`relay_stop.ps1` 与按命令行过滤的 kill 都碰不到它（提权进程的 `CommandLine`/`ExecutablePath` 读不到，`taskkill` 回「拒绝访问」）。解法：提权 PowerShell 里按 `ExecutablePath -like '*gadget-relay*'` 杀，再同一条命令里烧。
