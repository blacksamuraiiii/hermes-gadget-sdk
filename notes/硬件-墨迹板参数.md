# 墨迹板硬件参数（movecall-moji-esp32s3）

来源：`github.com/78/xiaozhi-esp32` 的 `main/boards/movecall/moji-esp32s3/`（config.json / config.h / movecall_moji_esp32s3.cc / README.md），2026-10-22 直取原文。
**判据：引脚与采样率只认这份 config.h，商品页与评测文经常写错屏驱和 codec。**

## 板型标识

```json
{"manufacturer": "movecall", "type": "movecall-moji-esp32s3", "target": "esp32s3"}
```

## 显示

| 项 | 值 |
|---|---|
| 面板驱动 | GC9A01（`InitializeGc9a01Display()`） |
| 分辨率 | 240 × 240，圆形 |
| 镜像 / 偏移 | mirror_x true、mirror_y false、swap_xy false、offset 0 / 0 |
| SPI SCLK | GPIO16 |
| SPI MOSI | GPIO17 |
| SPI CS | GPIO15 |
| SPI DC | GPIO7 |
| SPI RST | GPIO18 |
| SPI 时钟 | 40 MHz |
| 背光 | GPIO3（输出不反相） |

UI 由 `CustomLcdDisplay : SpiLcdDisplay` 在 `SetupUI()` 上扩展，改表情/界面先读这个类。

## 音频

| 项 | 值 |
|---|---|
| codec | ES8311（默认 I2C 地址） |
| 采样率 | 输入 24000 Hz / 输出 24000 Hz |
| I2S MCLK | GPIO6 |
| I2S WS (LRCK) | GPIO12 |
| I2S BCLK | GPIO14 |
| I2S DIN | GPIO13 |
| I2S DOUT | GPIO11 |
| 功放 PA | GPIO9 |
| codec I2C SDA | GPIO5 |
| codec I2C SCL | GPIO4 |

## 其它

| 项 | 值 |
|---|---|
| 板载灯 | GPIO21 |
| BOOT 键 | GPIO0 |
