## 显示

| 项 | 值 |
|---|---|
| 面板驱动 | GC9A01（`InitializeGc9a01Display()`） |
| 分辨率 | 240 × 240，圆形 |
| 镜像 / 偏移 | mirror_x true、mirror_y false、swap_xy false、offset 0 / 0 |
| SPI SCLK | GPIO16 |
| SPI MOSI | GPIO17 |
| SPI CS | GPIO15 |
| SPI DC | GPIO7 |
| SPI RST | GPIO18 |
| SPI 时钟 | 40 MHz |

## 板子实测（2026-10-23，COM5 串口日志）

- 主控 ESP32-S3-WROOM-1-N16R8；芯片 rev v0.2；PSRAM 8 MB Octal 80 MHz（vendor 0x0d AP）；Flash 厂牌 gd、QIO
- 出厂固件：小智官方 2.5.2（IDF v6.1 编译，2026-10-11），自报 `SKU=movecall-moji-esp32s3`
- Wi-Fi STA MAC `e4:b0:63:bb:77:84`，Board UUID `c4ff5fa2-2332-4ceb-b72c-0e2d7cc700a8`
- 串口：Windows `COM5`，`USB\VID_303A&PID_1001`，描述 `USB JTAG/serial debug unit`，Win10+ 免驱 CDC ACM
- 恢复出厂固件：小智发布页 `v<版本>_movecall-moji-esp32s3.zip` → `merged-binary.bin` 写 `0x0`

## 硬件补全（2026-10-23，立创开源硬件页）

- 麦克风 AP2718AT（模拟单麦）、功放 NS4150B、喇叭 2828-4R3W（4Ω 3W）、指示灯白色单色 LED
- 供电仅 USB-C 5V，**无电池、无充电管理**；外形 φ49.7 mm、37 g；PCB 2 层 1.6 mm 21×31.3 mm
- 无触摸、无 IMU、无 SD、无 RTC；硬件资料 CC BY-NC 4.0（不可未授权转载/商用）
