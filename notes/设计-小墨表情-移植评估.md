# 表情状态表移植评估（nous-girl → 我们的两块板）

日期：2026-11-05 · 来源：`dax8it/nous-girl-stackchan`（MIT，CC0 表情素材）
效果图：`emote-demo-240.png`（moji）与 Muse 目标区 `emote-demo-360.png`（1.85B）

## 结论先行

- **GIF 本身不可移植**：nous-girl 是 320×240 全屏 GIF（robot 全套 260KB，12 个动画），要 GIF 解码器 + 独立 assets 分区（0xB00000）。两块板都没有这套管线。
- **能移植的是“表”**：12 个名字 + 别名/回退链 + 触发条件 + 持续时间 + 大脑可调用。两边各有现成的脸渲染器接得住这张表，只是画法不同。
- **1.85B 走像素画，moji 走 1-bit 位图**，都不用新分区、不加解码器。

## nous-girl 原表（12 个）

neutral / happy / sad / thinking / sleeping / pet / shake / speaking /
listening / look_left / look_right / email，外加别名（loving→pet、crying→sad、
sleepy→sleeping、surprised→shake 等）与回退（缺哪个就近找 neutral）。
触发：聆听（说话时）、思考（等回答）、说话（按心情配嘴型）、中性闲置 120 秒→
sleeping、摸头→pet、摇晃→shake、点按→look_left/right、大脑工具 `robot_face`
或回复里的 emoji 决定心情。

## 1.85B（360×360 圆屏，Muse 像素头像）

- 现状：`muse_pixel.c` 已是模式驱动的脸——`muse_pose_t{mode, t, mode_t, level, happy}`，
  BOOT/IDLE/LISTENING/THINKING/SPEAKING/ERROR/OFF 各有眼/眉/嘴/腮红/特效
  （眨眼、视线游走、思考圆点、声波、爱心、感叹号），嘴型已有 SMILE/O/HMM/TALK/
  FLAT/GRIN 六种。缺的是“名字”：没有 emote 字段、没有别名表、没有大脑下发的脸。
- 移植做法：给 pose 加一个 emote 字段 + 一张名字→画法映射表 + 别名/回退；
  新画 6 个变体（sad、sleeping、pet、shake、look_left/right、email），其余
  6 个已有对应（neutral=IDLE、happy=`happy>0.2`、thinking、speaking、listening）。
- 代价：纯代码，约 0 Flash。1.5e 的 bin 已占 4MB 槽的 92%，GIF 路线本来就放不下，
  程序化是唯一可行的路；无新依赖、无分区改动。
- 接不到的触发：摸头、摇晃没有对应硬件（无触摸头顶、无 IMU），改走点按屏幕/
  宠物互动；email 改走提醒卡片。

## moji（240×240 圆屏，Hermes gadget core）

- 现状：core 自带 mascot 系统（`hg/mascot.hpp` + `mascot_data.cpp`），1-bit 位图，
  Idle/Blink/Talk 三帧 × 64/96/144/192 四档尺寸，`hermes-gadget face` 命令可从
  两色剪影 PNG 生成；`ui.cpp:draw_hero` 已画 mascot + 声波/思考圆点 + 字幕，
  `mascot_frame()` 按 Responding+speaking / 眨眼周期选帧。
- 移植做法：Frame 枚举加 Happy/Sad/Thinking/Sleeping/Listening 等帧，用同一
  生成器出图；`mascot_frame()` 改成按 `Screen`（Listening/Thinking/Responding/
  Idle）+ 闲置计时选帧；别名/回退表放 core；心情驱动（sad/happy）需协议或
  host 侧先给情绪来源，状态驱动的不需要。
- 代价：每新增一帧 × 四档尺寸约 9KB Flash（192px 1-bit 约 4.6KB），6 个新表情
  约 55KB；0.3 的 app 槽余约 1.86MB，放得下。无解码器、无分区改动。
- 接不到的触发：摸头、摇晃、左右看（无触摸/IMU/舵机）；email 可映射到提醒/
  批准卡片；白灯 GPIO21 只有一个，可做 thinking 时的弱脉冲，代替人家的 LED 配色。

## 建议的最小落地表（两边共用，6 个先行）

| 表情 | 触发 | 持续 | 回退 |
|---|---|---|---|
| neutral 中性 | 待机 / 连接中 | 直到变化 | — |
| listening 聆听 | 录音中 / 唤醒命中 | 到录音结束 | neutral |
| thinking 思考 | 等回答 | 到回答开始 | neutral |
| speaking 说话 | 播回答（按音量张嘴） | 到播完 | neutral |
| happy 开心 | 摸摸 / 心情好 | 3 秒 | neutral |
| sad 难过 | 难过心情 | 到下次变化 | neutral |
| sleeping 睡觉 | 中性闲置 120 秒 | 到任何动静 | neutral |

第二批再看：pet（摸头→点按代替）、shake（摇晃→无硬件，先不做）、
look_left/right（无舵机，先不做）、email（提醒卡片已在 0.3 落地，可复用）。
