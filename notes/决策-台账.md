### 2026-10-26 字库源：已定（保持像素字体）

- 现役：Fusion Pixel 12px（OFL 1.1），12×12 位图，实测清晰。
- 候选（用户提出）：文泉驿微米黑（Apache 2.0 / GPLv3 双许可；GB2312 一级 3755 + 二级 3008 零缺字，已实测）。

### 2026-10-26 发版口径：fork 的 tag 用 `moji-0.x`，Release 只发在 fork

- 背景（实测，不是推测）：
  - 上游 tag 已占用 `v0.1.0 / v0.1.1 / v0.2.0 / v0.3.0 / v0.4.0 / v0.4.1`（本地与远端都有，指向上游提交），fork 再用 `v0.x.y` 会与上游同名。
  - `gh` 在本仓库默认解析到 `Adolanium/hermes-gadget-sdk`（`gh repo view` 实测 `isFork=false`），不带 `-R` 的 `gh release` / `gh repo` 会打到上游。
- 拍板：
  - **发布 tag 命名 `moji-0.1` / `moji-0.2`**（两位，前缀 moji，与上游彻底分开）。`moji-0.1` 已存在：附注 tag，指向 `86381e5`（0.1 交付提交）。
  - **固件 `PROJECT_VER` 仍写三段式 `0.1.0` / `0.2.0`**：`plugin/cli.py:_version_key` 用 `(\d+)\.(\d+)\.(\d+)` 比较，两位版本会被判「版本未知」而拒绝升级。映射固定为 `moji-0.X` ↔ `0.X.0`。
  - **所有 `gh release` / `gh repo` 命令必须显式 `-R blacksamuraiiii/hermes-gadget-sdk`**，发布前用 `gh release view -R …` 复核落点，发布后核对资产清单。
  - Release 资产：四个 bin + `SHA256SUMS` + `README.md`；仓库里只留 `README.md` 与 `SHA256SUMS`，bin 不进 git（`.gitignore` 挡住后续）。
  - 待办：插件 `releases.py` 的 `RELEASES` 指向 fork 时，`download_app()` 拼的是 `download/v{version}/{path}`，而 fork 的 tag 是 `moji-0.X` —— manifest 必须带 `tag` 字段并让 `releases.py` 优先用它，否则自动更新 404。此项等 fork 出了带 manifest 的 Release 再做。
