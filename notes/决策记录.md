## 事实基线（改动前先复核）

- 本板在 `78/xiaozhi-esp32` 的官方板型目录里 → 小智固件可直接烧
- 本板**不在** `Adolanium/hermes-gadget-sdk` 的支持表 → 要接 gadget 必须自己 port
- 同尺寸的 Spotpear ESP32-S3-1.28-BOX 与本板驱动/引脚不同，不可照抄
- 本机当前无 ESP-IDF、esptool、cmake、g++；Python 3.11.15 可用

## 悬而未决

1. **路线 B 的 port 起点选谁**——要等读到 SDK 的 `docs/porting.md` 与几个同族板 profile 源码后才能定，现在定属拍脑袋。
2. **模拟器能否在 WSL 跑通**——WebSocket 没问题，音频设备在 WSL 的可用性未验证；若不通，模拟器改在 Windows 侧跑。
3. **刷写通道**——WSL 看不到 USB 串口，走 Windows 侧工具还是 USB 透传，实测后定。
4. **语音链路**——Hermes 侧需配 ASR/TTS，当前是否已配未查。
