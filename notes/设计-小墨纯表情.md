# 小墨纯表情分支说明（feat/moji-emoji-only）

- 日期：2026-11-08
- 基点：`feat/moji-0.4` 头 `2303625`（含表情扩展设计稿）
- 状态：分支说明，未动代码；脸的几何见 `notes/设计-小墨表情-扩展.md`
- 证据标记：`[码]` 源码 · `[测]` 实测/既有测试 · `[推]` 推断 · `[?]` 待核实

## 0. 这分支是什么

纯表情变体：屏上只有表情，没有中英文文字。**与 0.4 文字版并存，不是替代**——
提醒屏（提醒卡、回复正文、设置页）仍在 0.4 那条线；这条线做纯陪伴。

## 1. 舍弃的

- 机器人头（`robot_face.cpp` 的头框、耳朵、嘴、天线杆 + 球）全部不要。
- 所有中英文文字 UI：回复正文、提醒卡、设置页、状态行、配对码显示。
- 16px 字体问题随之消失（字体表、西班牙语溢出、行盒 22 都不用再管）。

## 2. 留下的

- Otto 眼睛-only 脸：12 态几何见扩展稿（`notes/设计-小墨表情-扩展.md` §3），
  240 帧原样画，不嵌 GIF。
- 没有状态点：连接态用脸表示（见 §3）：连接中是转圈脸，连接不上是 XX 眼；
  连上之后就是正常脸（中性即已连接），不需要常驻指示。

## 3. 关键设计点与还没定的

1. **说话态 / 聆听态已重设计（v4，2026-11-08，用户口径）**：眼睛靠左，右侧竖
   wifi 波形。**聆听**：眼睛靠左 + 右侧 wifi 波形，弧口朝右（耳朵对着外面），
   声音从右边进来；**说话**：眼睛靠左 + 右侧 TTS 波形（🔊 式），弧口朝左，
   声音往右边去。方向区分两者（v2 的波形线 / 均衡条、v3 的双侧声波均作废）。
   效果图 `emote-pure-ui-v4.png`。
2. **连接态也用脸（v3，2026-11-08，用户说状态点上下都怪）**：状态点彻底
   不要。**连接中**：眼睛 + 蓝色转圈环绕整张脸（缺口在顶部，动画时旋转），
   通用 loading 语言；**连接不上**：XX 眼（机器人脸通用的“坏了 / 离线”）。
   映射走现有 link 态：连接中（黄）→ 转圈脸，连接不上（红）→ XX 眼，
   已连接（绿）→ 正常脸。效果图 `emote-pure-ui-v3.png`。
3. **配网 / 配对码离不开文字**：首次配网选 SSID、输配对码，屏上没字做不了。
   两个口子二选一：① 只在配网时出现一个极简文字页，配完即走；② 配网全走
   手机 App，屏上只显示配网中表情。100% 无文字做不到。
4. **心情驱动是关键路径**：没有 host 心情（Phase 2），纯表情分支大部分时间
   只能显示状态脸（中性 / 聆听 / 思考 / 睡觉 / 困惑），大笑、喜欢、惊讶、眨眼
   用不上。先做 Phase 2 还是先上状态脸，得排个序。
5. **文字提示音**：回复只靠语音播，听不清没法回看——接受，还是留一个
   “点一下重播”的手势？

## 4. 移植顺序

1. 状态脸（neutral / listening / thinking / sleeping / confused）+ 连接态两张脸
   （connecting / disconnected）。
2. 说话态动画（§3.1 已定稿）。
3. Phase 2 心情 4 态（laughing / loving / surprised / winking）。

## 5. 不做的

- 不引 GIF 解码器、不加 assets 分区、不嵌 941KB GIF（同扩展稿）。
- 不动 `main`、不动 `feat/moji-0.4`；这分支的改动只走这条线。
