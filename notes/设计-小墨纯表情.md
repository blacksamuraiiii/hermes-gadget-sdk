# 小墨纯表情分支说明（feat/moji-emoji-only）

- 日期：2026-11-08
- 基点：`feat/moji-0.4` 头 `2303625`（含表情扩展设计稿）
- 状态：第一批（状态脸 + 连接态）与第二批（说话动画 + 7 张心情脸）与第三批（兴奋、无聊 2 张心情脸，补齐 20 张）均已落地，见 §4；脸的几何见 §3 总表与 `notes/设计-小墨表情-扩展.md`
- 证据标记：`[码]` 源码 · `[测]` 实测/既有测试 · `[推]` 推断 · `[?]` 待核实

## 0. 这分支是什么

纯表情变体：屏上只有表情，没有中英文文字。**与 0.4 文字版并存，不是替代**——
提醒屏（提醒卡、回复正文、设置页）仍在 0.4 那条线；这条线做纯陪伴。

## 1. 舍弃的

- 机器人头（`robot_face.cpp` 的头框、耳朵、嘴、天线杆 + 球）全部不要。
- 所有中英文文字 UI：回复正文、提醒卡、设置页、状态行、配对码显示。
- 16px 字体问题随之消失（字体表、西班牙语溢出、行盒 22 都不用再管）。

## 2. 留下的

- Otto 眼睛-only 脸：20 态几何见 §3 总表（小墨表情包全套 20 张，全部已移植），
  240 帧原样画，不嵌 GIF。底眼统一为高瘦椭圆（见 §3.6）。
- 没有状态点：连接态用脸表示（见 §3）：连接中是转圈脸，连接不上是 XX 眼；
  连上之后就是正常脸（中性即已连接），不需要常驻指示。

   `firmware/core/src/emoji_face.cpp` + `include/hg/emoji_face.hpp`（新渲染器，

   留在树里给 0.4 线）。`emoji_look`：link 优先（connecting/network → 转圈，
   offline → XX），再 emote，再 screen。另含 happy / sad（唤醒命中 / 无语音
   回合的 Phase 1 反馈，本来就是状态驱动）与 speaking 静态形（眼下小波形，

## 5. 不做的

- 不引 GIF 解码器、不加 assets 分区、不嵌 941KB GIF（同扩展稿）。
- 不动 `main`、不动 `feat/moji-0.4`；这分支的改动只走这条线。

## 6. 2026-11-09 收口：无文字 + 提醒表情 + 脸占满屏

- **屏上不再有任何文字**（用户拍板）：`draw_header`、`draw_hero` 的 caption、
  `draw_content` 三处对 `m.emoji` 短路；app 层同时清空 headline / detail / body /
  yes / no / hint / qr / dash 并强制 `hero = true`。此前只拦了 header 与 caption，
  长回复改走文字屏那条路仍会出中文。
- **脸按整屏缩放**：`hero_geom` 里「板画自己的脸」原来只判断 `m.robot`，emoji 落回
  mascot 的 64/96/144/192 阶梯。现与 robot 同等待遇（主区按整屏、按 `emoji::zoom()`
  反算上限、自由缩放）。真机实测 `hg: hero: size 64 at y 58` →
  `size 171 at y 3, band 206`，占可用区 83%。
- **三类提醒配表情**：协议 `prompt` / `display` 消息新增 `kind` 字段（插件
  `hub.ask(..., kind=)` 取 `_Prompt.kind`，`hub.show_card(..., kind=cue)` 取提醒 cue 名），
  固件 `h_prompt` / `h_display` 读它写入 `Notice`，`emoji_look` 在 emote 之前映射：
  **授权 approval → Silly(?)、选择 clarify/slash → Shocked(!!)、完成 done → Happy(摇沙锤)**，
  保持 `kNoticeMs = 8 s` 后回到状态脸（用户拍板：统一 8 秒）。
- **模拟器出图仍不可用**：`rgb888()` 读到全黑 framebuffer（`sim-320x240` 与 `sim-moji`
  都是 0 个非黑像素），与 emoji 代码无关，待查。这轮的观感只能以真机为准。

## 7. 2026-11-09 第二轮：动起来、按屏、交给 AI

- **动画**：Neutral 加 40 帧扫视（眼睛 ±7 设计单位左→右）；Speaking 改**固定 20 帧波形**，
  不取麦克风（单麦无 AEC，播放时的电平要么是她自己要么是过期值，实测把六根柱压成五颗点）；
  `hero_anim_rows` 对 emoji 改按**整块脸**重绘——原先沿用 mascot 的 `eyes_y0/y1` 千分比，
  只刷上半部，眨眼/扫视时下半只眼睛不动。
- **按屏**：板级与 sim-moji 的 `round_area_permille` 860→1000（没有文字要避圆角）。
  实测 `hero: size 171, band 206` → `size 199, band 240`，脸渲染 240 占满整块玻璃。
- **静息**：每 20 秒随机换一张，池八张（中性/酷/开心/无聊/喜欢/兴奋/Hi/傻），不连出同一张；
  2 分钟进睡觉（阈值不变）。`pick_idle_look()` 用 `hal.system.random_bytes`。
- **提醒三连**：授权→Silly(?)、选择→Shocked(!!)、完成→Happy，各 8 s（`Notice`）。
- **优先级**（2026-11-09 用户拍板）：链路 → 唤醒应答 → 播报中 Speaking → 阻塞型提醒 →
  AI 指定 → 场景。AI 表情与提醒撞车时提醒赢，不补显示。
- **唤醒应答**：说「我在」时给 Happy（摇沙锤）而不是 Speaking 的音量柱——
  `UiModel.wake_cue = wake_awaiting_cue_ && speaking()`。
- **AI 链路**：`emote` 消息 `{look, ttl_s}` → `h_emote` → `named_look_`；
  插件 `hub.emote()` + `gadget_face` 工具（20 态 enum）；profile `gadget-emoji`。
  播报中到达的 emote 进 `pending_look_`，播完才起算 ttl。`caps.face` 上报
  emoji/robot/mascot，非表情板返回 `not_shown`。
- **连接环**：从 emoji_face 移到 `Ui::draw_hero`，按面板尺寸画（模拟器实测半径
  89.2~99.5 px，可用半径 103），脸本身回到中性。
- **遗留**：① 2026-11-09 13:04 有一次唤醒后卡在录音态、后续命中全被 `mode != Idle` 挡掉，
  已加 gate 诊断日志，待复现定位；② 模拟器出图必须先 `sim.start()`，否则 `rgb888()` 读到全黑。
