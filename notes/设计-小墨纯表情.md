# 小墨纯表情分支说明（feat/moji-emoji-only）

- 日期：2026-11-08
- 基点：`feat/moji-0.4` 头 `2303625`（含表情扩展设计稿）
- 状态：分支说明，未动代码；脸的几何见 `notes/设计-小墨表情-扩展.md`
- 证据标记：`[码]` 源码 · `[测]` 实测/既有测试 · `[推]` 推断 · `[?]` 待核实

## 0. 这分支是什么

纯表情变体：屏上只有表情，没有中英文文字。**与 0.4 文字版并存，不是替代**——
提醒屏（提醒卡、回复正文、设置页）仍在 0.4 那条线；这条线做纯陪伴。

## 1. 舍弃的

- 机器人头（`robot_face.cpp` 的头框、耳朵、嘴、天线杆 + 球）全部不要。
- 所有中英文文字 UI：回复正文、提醒卡、设置页、状态行、配对码显示。
- 16px 字体问题随之消失（字体表、西班牙语溢出、行盒 22 都不用再管）。

## 2. 留下的

- Otto 眼睛-only 脸：12 态几何见扩展稿（`notes/设计-小墨表情-扩展.md` §3），
  240 帧原样画，不嵌 GIF。
- 状态灯回到顶部小点：屏顶正中 (120, ~16)、半径约 4 px，按连接态着色
  （绿 / 黄 / 红，与现天线球同色）；录音时可另闪，不与脸抢视觉。
  惊讶眼顶 y=63，小点不与任何态重叠。

## 3. 还没定的（动手前先拍板）

1. **说话态没嘴了**：眼睛怎么表示“正在说”？候选：眼睛 + 三道声波（沿用
   Listening 的波形）、或整脸轻晃。Otto 包里没有说话动画，得新画。
2. **配网 / 配对码离不开文字**：首次配网选 SSID、输配对码，屏上没字做不了。
   两个口子二选一：① 只在配网时出现一个极简文字页，配完即走；② 配网全走
   手机 App，屏上只显示配网中表情。100% 无文字做不到。
3. **心情驱动是关键路径**：没有 host 心情（Phase 2），纯表情分支大部分时间
   只能显示状态脸（中性 / 聆听 / 思考 / 睡觉 / 困惑），大笑、喜欢、惊讶、眨眼
   用不上。先做 Phase 2 还是先上状态脸，得排个序。
4. **文字提示音**：回复只靠语音播，听不清没法回看——接受，还是留一个
   “点一下重播”的手势？

## 4. 移植顺序

1. 状态脸（neutral / listening / thinking / sleeping / confused）+ 顶部小点。
2. 说话态动画（§3.1 定稿后）。
3. Phase 2 心情 4 态（laughing / loving / surprised / winking）。

## 5. 不做的

- 不引 GIF 解码器、不加 assets 分区、不嵌 941KB GIF（同扩展稿）。
- 不动 `main`、不动 `feat/moji-0.4`；这分支的改动只走这条线。
