# 路线 A：小智固件（xiaozhi-esp32）

**目的**：板子到手后第一件事——用现成固件验证硬件（屏 / 麦克风 / 喇叭 / 背光）都正常，为后续 hermes-gadget port 排除硬件变量。

## 前提

- ESP-IDF（数 GB，未安装）
- 本板已在官方板型列表：`main/boards/movecall/moji-esp32s3/`

## 步骤

```bash
# 1. 取源码（Gitee 镜像快，GitHub 为准）
git clone --depth 1 https://github.com/78/xiaozhi-esp32.git
cd xiaozhi-esp32

# 2. 目标芯片
idf.py set-target esp32s3

# 3. 选板（菜单项原文）
idf.py menuconfig    # Xiaozhi Assistant -> Board Type -> Movecall Moji 小智AI衍生版

# 4. 编译
idf.py build

# 5. 烧写与看日志
idf.py -p <PORT> flash monitor
```

## 判据（做完算不算过）

- 屏幕点亮并显示待机表情 → 屏驱与背光对
- 按键按下有反应 → BOOT（GPIO0）通
- 说话有回声/回答 → 麦克风、ES8311、功放（GPIO9）全链路通
- 能连 WiFi → 配网流程正常

四项都过再谈 port；有一项不过，先查硬件与引脚，不要怀疑移植代码。

## 坑

- **WSL 看不到串口**：`/dev/ttyACM*`、`/dev/ttyUSB*` 常不存在。刷写走 Windows 侧 esptool，或先做 USB 透传进 WSL；未实测前不要承诺「一条命令刷完」。
- **`idf.py monitor` 退出快捷键**：Ctrl+]（不是 Ctrl+C）。
- **menuconfig 选了板 ≠ 音频通**：codec 地址、PA 引脚、I2C 引脚仍要按 `硬件-墨迹板参数.md` 对一遍。
- **别搬 build 目录**：`CMakeCache.txt` 记着原源目录，换位置会直接报错，需重跑配置。
