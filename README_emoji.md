# 小墨 · 纯表情包说明书（feat/moji-emoji-only）

> 20 张表情全部由 `hg::emoji::draw()` 用 Canvas 几何直绘，240 px 设计帧；不嵌 GIF、不引解码器，
> 所以每个表情只花几十字节代码而不是几百 KB 位图。下表 GIF 就是**固件渲染器实际输出的 20 帧**
> （`tools/make_emoji_gifs.py` 生成，见文末），不是设计稿示意：屏上看什么，这里就是什么。

## 二、设计理念

1. **眼是主角，其余是optional。** 20 张里 14 张保持同一对「高瘦椭圆（50×100，(72,112)/(145,112)）」
   底眼，表情靠配饰区分（思考的三个点、聆听的三条弧、说话的音量柱、连接的黄圈、傻的 ? 眼、
   酷的墨镜）。表情不靠嘴——圆屏上嘴是很容易画坏的东西。
2. **心情不讲逻辑，讲可见度。** 大笑、喜欢、生气、震惊、尴尬、兴奋这六张直接用**眼睛本身**当表情，
   这类眼睛（><、爱心、怒眼、实心圆、压扁、星星）在全局 blink 里豁免——它们一闭眼表情就没了。
   豁免清单：`Happy / Sleeping / Disconnected / Laughing / Loving / Excited / Bored / Cool / Hi`。
3. **同一个 240 px 帧，zoom 1.2。** 所有几何以 240 设计帧为单位从 Canvas 原语绘出
   （`FacePen` 统一做缩放映射），`HG_EMOJI_ZOOM` 默认 1.2：脸盒 200 px 时实际画到 240。
   连接上的黄圈是唯一例外——它是**玻璃的边缘语言**，所以画在面板帧里贴着屏幕走。
4. **不做用不到的事。** 不嵌 941 KB GIF、不加 assets 分区、不写动画脚本：每个表情就是一段
   几何 + 一个相位函数（`gif_phase`），动效成本是每帧十几次 fill 而不是一帧图片。

## 三、静息不无聊

长时间待机时，**每 20 秒随机换一张静息表情**，直到睡着——这是「20 张不能只停在一两张」的底线。
轮换池八张（不会连出同一张）：中性（扫视）、酷（墨镜）、开心（沙锤）、无聊（半沉眼）、
喜欢（爱心）、兴奋（星星眼）、Hi（射线）、傻（问号）。

  < 2 min   每 20 s 随机从上面六张里挑一张
  ≥ 2 min   睡觉（z 的短暂出现是这一轮的下限）

提醒三连（8 秒一窗，结束回静息）：

  绑授权 → 傻（?）
  绑选择 → 震惊（!!）
  绑完成 → 开心（沙锤）

## 四、AI 挑表情（已接）

`gadget_face(look, seconds=8)` 是 agent（Hermes）的唯一表情入口：

- 插件 `plugin/tools.py` 注册进 gadget 工具集，enum 列全 20 态，`hub.emote()` 发
  `{"emote": {"look": "...", "ttl_s": 8}}`；
- 固件 `h_emote()` 把名字映射成 `emoji::Look`，存 `named_look_` 并按 ttl 过期；
  `emoji_look()` 里 **named look 优先于 notice / link / screen**——它是 AI 对这一轮
  内容的判断，比状态推断更该说话；
- profile `gadget-emoji` 的 SOUL.md 写明：屏上只有表情、回复仍朗读、一轮最多调一次、
  情绪不明显就不调（交给静息轮换）。

带上这张链路后，标 **Phase 2** 的 9 张（大笑/喜欢/生气/尴尬/眨眼/兴奋/无聊 + Silly + Hi）
就不再是摆设：AI 按对话内容挑，`listening`/`speaking`/`connecting`/`disconnected`
仍归设备自己管。

## 五、复现

```bash
g++ -std=c++17 -I firmware/core/include firmware/tools/dump_emoji.cpp \
    build-emoji/core/libhg_core.a -o /tmp/dump_emoji
/tmp/dump_emoji                      # 20 looks × 20 frames → /tmp/emoji-frames/*.ppm
python tools/make_emoji_gifs.py      # .ppm → assets/emoji/*.gif
```
